🌐 My Portfolio Website
📖 Overview

This is a personal portfolio website created using HTML and CSS.
It showcases my profile, skills, education, and projects in a clean and responsive design.
The website adjusts its layout on mobile and desktop using CSS Media Queries.

🧑‍💻 Features

Clean and modern design

Fully responsive using media queries

Navigation bar with smooth scrolling

Sections for About, Skills, Projects, Education, and Contact

Footer with copyright and social links

🏗️ Technologies Used

HTML5 – for structure

CSS3 – for styling and layout

Media Queries – for responsive design

📂 Folder Structure
project-folder/
│
├── index.html       → Main HTML file  
├── style.css        → CSS styling  
└── assets/          → Folder for images or icons (optional)

🧱 Sections in the Website

Header – Name, profession, and navigation menu

About Me – Short introduction

Skills – Technical and soft skills

Projects – Showcase of work with links

Education – Academic details

Contact – Email, GitHub, and LinkedIn

Footer – Copyright note

🧭 Navigation Links

Each navigation link (like “About”, “Skills”, “Projects”) connects to its respective section using id attributes.
Example:

<a href="#about">About</a> → <section id="about">...</section>


These links work smoothly due to:

html {
  scroll-behavior: smooth;
}

📱 Responsive Design

Media queries are used to make the website mobile-friendly:

@media (max-width: 768px) {
  /* Tablet layout adjustments */
}

@media (max-width: 480px) {
  /* Mobile layout adjustments */
}


This ensures the layout adapts for small screens like tablets and phones.

🚀 How to Run

Download or clone the project folder.

Open index.html in any browser (Chrome, Edge, Firefox).

Make sure style.css is linked correctly in the HTML file.
